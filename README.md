# Iqra Anees — Interactive Portfolio

A personal portfolio website 

## 📁 Files
- `index.html` — Main HTML structure
- `style.css`  — All styles (dark editorial theme, gold accents)
- `script.js`  — Interactions, animations, scroll effects

## ✨ Features
- Custom animated cursor with trailing ring
- Typing animation in hero section
- Scroll-triggered reveal animations for every section
- Parallax hero background text
- 3D tilt effect on achievement cards
- Reading progress bar at top of page
- Active nav link highlighting on scroll
- Smooth scroll navigation
- Fully responsive (mobile-friendly)

## 🎨 Design
- **Aesthetic:** Editorial dark luxury
- **Display font:** Cormorant Garamond (serif)
- **UI font:** Syne (sans-serif)
- **Code font:** JetBrains Mono
- **Primary accent:** Gold (#c9a96e)
- **Background:** Deep dark (#0a0a0c)
